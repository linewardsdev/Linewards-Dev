# Line Wards LTW Graphics Art Direction

Use this skill for graphics, art direction, visual design, UI presentation, board readability, asset direction, VFX feedback, and concept-art prompt work on Line Wards.

Scan-level guidance:

- Preserve the Line Tower Wars feel: active lane first, visible spawn/exit, open-lane mazing, obvious tower blockers, readable creep pressure, lives/gold/income/tick status, and satisfying send-for-income feedback.
- Translate the reference into an original Line Wards style: mobile-readable ward-tech fantasy with strong silhouettes, restrained effects, and the brand palette from `docs/BRANDING_GUIDE.md`.
- Do not copy Warcraft III or Blizzard names, models, textures, icons, sounds, UI frames, command-card layout, faction symbols, unit silhouettes, screenshots, or race architecture.
- Before making visual changes, read [line-tower-wars-graphics-art-direction.md](line-tower-wars-graphics-art-direction.md) for the detailed visual doctrine, research references, acceptance checks, and asset rules.
