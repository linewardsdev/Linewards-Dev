# UI Board Pipeline Workspace

This folder is for UI and board art planning artifacts that do not belong in Unity yet.

Use it for:

- contact sheet notes;
- selected candidate tables;
- rejected candidate notes;
- prompt iterations;
- component inventories;
- small review collages.

Keep generated source images and Unity production sprites separate:

- review images and notes: `docs/art-pipeline/ui-board/`
- screenshot QA: `docs/screenshot-reviews/ui-board-art-pass-vXX/`
- Unity source art: `unity/LTW.UnityClient/Assets/Art/UI/` and `Assets/Art/Board/`
- Unity runtime icons: `unity/LTW.UnityClient/Assets/Resources/Art/UI/Icons/`
