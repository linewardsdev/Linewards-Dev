# Numbered Contact Sheets

These are review copies of the original contact sheets. The unnumbered originals remain one folder up.

Numbering convention:

- 1-4: top row, left to right.
- 5-8: middle row, left to right.
- 9-12: bottom row, left to right.

Use feedback like `Arrow 7`, `Runner 2`, or `Builder 10` when selecting candidates.
