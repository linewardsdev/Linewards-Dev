# AI Art Review Notes

Use one review file per role and generation pass.

Required sections:

- Role and pass number.
- Prompt/library version.
- Tool/model used.
- Contact sheet path.
- Selected candidate.
- Rejected candidates and reasons.
- Phone-scale readability verdict.
- Grayscale readability verdict.
- Protected-IP/provenance verdict.
- Next action: reject, regenerate, clean source plate, implement token, or screenshot QA.
