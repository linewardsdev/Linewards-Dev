# Creep Art Source

Use these folders for source meshes, concept references, texture sources, and iteration notes for the MVP creep set.

Keep the visual language original ward-tech fantasy: arcane constructs, signal fragments, rune plates, glass cores, prism bodies, and clean mobile silhouettes. Do not use Warcraft, Blizzard, medieval faction, or RTS nostalgia styling.

Use `docs/ART_THEME_AND_ROLE_GUIDE.md` as the shared source of truth for role silhouettes and motifs.

The first polished set should cover:

- Runner
- Brute
- Swarm
- Shade
- Siege

Validate each role at phone size and under heavy-send pressure before expanding to boss, air, advanced stealth variants, or aura/support creeps.
