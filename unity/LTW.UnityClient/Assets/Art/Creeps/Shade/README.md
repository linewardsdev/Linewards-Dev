# Shade Creep Art Notes

Low-visibility pressure creep assets belong here.

Role read:

- Shimmering signal ghost or translucent shard construct.
- Small/fast read, distinct from Runner by echo rings or offset afterimages.
- Must remain readable in reduced-effects mode; do not rely on transparency alone.
- Avoid undead, demon, or fantasy monster language.

Runtime id: `creep.shade`
