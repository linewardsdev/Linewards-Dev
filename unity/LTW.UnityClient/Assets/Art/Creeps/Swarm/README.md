# Swarm Creep Art Brief

Concept: signal mites or shardlings.

Read target:

- Several tiny bodies that read as one clustered unit.
- Reads as volume pressure.
- Uses jittered offsets and a shared sender-color accent.
- Must remain readable when many swarms overlap in the same lane.

Avoid organic horror detail, gore, or tiny high-frequency texture noise that disappears at phone size.
