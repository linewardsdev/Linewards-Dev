# AI Staging

Generated or AI-assisted source material lives here before it is approved for production. Nothing in this folder should be wired directly into runtime prefabs or gameplay code.

Folders:

- `Concepts/`: rough ideation and contact-sheet exports.
- `SourcePlates/`: approved transparent source plates awaiting Unity conversion.
- `Rejected/`: rejected candidates kept for review traceability.

Only move assets into `Assets/Art/Towers/Production/` or `Assets/Art/Creeps/Production/` after review notes and provenance are complete.
