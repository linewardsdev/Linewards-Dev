# Tower Art

Tower source art is grouped by role: Arrow, Control, Relay, Pulse, and Prism.

Use `docs/ART_THEME_AND_ROLE_GUIDE.md` as the shared source of truth for role silhouettes and motifs.

Use names such as `tower_arrow_body_v01`, `tower_control_ring_v01`, and `tower_relay_signal_v01`.
Runtime prefab requirements are documented in `docs/ART_PREFAB_CONTRACT.md`.
